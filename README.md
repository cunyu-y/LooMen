This repo contains the data and code used for the study presented in the following paper:

Depression risk associated with idealized sentiment toward urban places on social media

This paper has been accepted by Nature Cities.

The raw data analysed in this study are available at https://github.com/ethan-nicholas-tsai/SWDD and are not redistributed here. Please obtain them from the original source if needed.

Cite our paper here:
Yuan, C., Zhang, X., Tang, L. et al. Depression risk associated with idealized sentiment toward urban places on social media. Nat Cities 3, 916–928 (2026). https://doi.org/10.1038/s44284-026-00516-x
